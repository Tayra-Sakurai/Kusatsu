# Kusatsu

Kusatsu is a Windows application for your personal budget management.

This application helps you manage your spendings privately.

You can use this application **completely for free** under the terms of [**GNU Affero General Public License version 3.0 or later**](https://spdx.org/licenses/AGPL-3.0-or-later).

This application is built with **zero cloud concept**.
Therefore, none of your personal data could be sent to the Internet in normal operations.

## Core Features

This application is made to help with the user's financial management easily.

### Recording Feature

You can add an item to the local database by filling a form.

The category of the item is suggested by the local AI named Perry if the user enables the AI feature and has installed [Ollama](https://ollama.com/) on your computer.

You can use this feature for managing financial state at home.

### Budget Settings

You can set monthly budgets for each category.
The budget can be distributed for each child categories.

You can be assisted by Perry when you enable it.
Perry can access your database privately to suggest your budgeting plan only if you granted access.
