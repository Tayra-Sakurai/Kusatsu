# Kusatsu - Agent Instruction

## Overview

This is an application software repository for personal budgeting.

This application is built on **zero cloud philosophy**.
It means that any cloud AI tools or cloud-based database is not contained in this application's operations.

This application is built with .NET version 10.0 with Windows App SDK 2.6.4 and WinUI.
[Ollama](https://ollama.com/) runs the AI tools for this application via `OllamaSharp`.

## Structure

- `Kusatsu/` has the UI and other front-end modules of this application.
- `Maiko/` has the database backend modules powered by EF Core 10 and Sqlite.
- `Tayra.CommunityToolkit.Localized.Mvvm/` contains the validation attributes set for locaized error messaging.

## Setup and Development

### Prerequisities and Environment

* **Operating System**: Windows 11 22H2 or later.
* **Developer Mode**: Must be enabled for local registration and testing.
* **SDKs**:
  * [.NET 10.0 SDK](https://dotnet.microsoft.com/)
  * Windows App SDK 2.6.4 and some other NuGet packages (automatically managed via `dotnet restore`)

### Build and Run Commands

```bash
# Restore the packages.
dotnet restore

# Build the solution
msbuild Kusatsu.slnx /p:Configuration=Debug /p:Platform=x64
```

## Code Conventions

1. Please ensure a new project's `TargetPlatform` to `net10.0-windows10.0.26100.0`.
1. Please ensure a new project's `TargetPlatformMinVersion` to `10.0.22000.0`.
1. Please do not customize the default styles of controls unless you strictly need to do.
1. **Never** introduce new external dependencies without the user's explicit approval.
1. Do keep modular architecture of this repository.
1. **Never edit this file.**
1. **Never introduce cloud-based dependency.**

## Gotchas

- Do not edit files in `obj/` or `bin/` folders. Your modifications on these files never reflected on the final assembly because these are generated by .NET.
